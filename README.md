# Testscope 評価用モック

問題・問題セットの品質レビューを評価する操作用モックです。

## 評価の流れ
1. 品質サマリーで出題内容と難易度の分布を確認する。
2. 「3問を確認する」から問題を開く。
3. 項目特性曲線と答案の該当箇所を確認する。
4. 「AIに改善案を聞く」で定型回答を表示し、コメントへ引用・保存する。
5. 要改善マークを付け、一覧で絞り込む。
6. 共通問題・IRTキーで候補比較と設定を試す。
7. データ・資料でファイル選択と洗い替えの操作を試す。
8. シリーズと各回を追加し、実施期間を登録する。

## 模擬動作と制限
- 全数値、問題、答案、グラフは架空の見本。IRT曲線は模式図。
- AIは定型回答。実際の生成AI・OCR・IRT計算・CSV内容検証は未接続。
- ファイルは外部送信せず、名前だけページ内に反映する。
- マーク・コメント・設定・新規登録はページのメモリ内のみ。再読込でリセット。
- 5教科は操作評価用の見本を共有。分類階層の切替も表示例。
- 印刷/PDFはブラウザ印刷。レポートはMarkdown形式。
- MCP/WebMCPはユーザー指定に従いサンプル対象外。
- 実際の個人情報や答案を入力しないこと。

## 検証
- production build 成功。
- TypeScript型チェック成功。
- ローカルHTTP応答200を確認。
- ブラウザでの操作・視覚テストは未実施。
